# Contributing to Claude Instruction Design System

Thank you for your interest in contributing! This project welcomes contributions from the community.

## How to Contribute

### Reporting Issues
- Check existing issues first
- Provide clear description of the problem
- Include examples where possible
- Describe your use case

### Suggesting Enhancements
- Describe the enhancement and why it would be useful
- Provide examples of how it would work
- Consider how it fits with the friction-driven philosophy

### Contributing Examples
We welcome examples from different domains:
- Fill in starter template for your domain
- Document your friction-driven evolution
- Show real memory instructions you've created
- Submit as PR with clear description

### Contributing Documentation
- Follow single source of truth principle
- Check PROJECT-INDEX.md for where information belongs
- Link rather than duplicate
- Keep examples domain-authentic (no cross-contamination)

### Pull Request Process
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test your changes (does documentation read clearly?)
5. Submit PR with clear description
6. Be patient - we'll review as soon as possible

## Code of Conduct
- Be respectful and constructive
- Focus on the work, not the person
- Welcome newcomers
- Assume good intentions

## Questions?
Open an issue with the "question" label.
