# Career & Coding Example - Evolution Timeline

Shows how a self-taught developer project evolves from Day 1 through Month 2 using friction-driven development.

---

## Day 1: Initial Setup (30 minutes)

### Layer 1: Personal Preferences (Account-wide)
- Ask clarifying questions rather than making assumptions
- Flag when I'm solving the wrong problem
- Use concrete examples to illustrate abstract concepts

### Layer 2: Project Context (Five Essentials)

**Context:**
Transitioning to software development through self-study. No CS degree but 3 years project management experience. Learning Python and web fundamentals. Good at concepts, struggle with practical application. Full-time job limits learning time.

**Constraints:**
- Time: 8-12 hours/week outside work
- Resources: Computer, VS Code, GitHub, basic dev tools, no mentorship
- Budget: ~£50/month for courses/books/tools
- No CS degree, limited tech network, tendency toward tutorial hell

**Goals:**
- Build 3-4 portfolio projects demonstrating real skills
- Develop Python and web fundamentals to employable level
- Land first developer role or freelance work within 12 months

**Preferences:**
- Push me toward building over consuming tutorials
- Be direct about code quality (want honest feedback)
- Help distinguish "good enough to ship" from "needs improvement"

**Red Flags:**
- Don't suggest bootcamps or full-time study (not viable)
- Don't recommend learning 5 frameworks before building (leads to paralysis)
- Don't assume I have mentors or senior devs to review my work
- Don't compare timeline to people with CS degrees

### Layer 3: Project Memory
Empty - will build through friction

---

## Week 1: First Friction Patterns (15 minutes)

**What caused friction:**
- Code explanation level: Used "memoization", "lexical scope", "pure functions" without defining (3x) → AI assumes CS knowledge I don't have
- Suggesting full rewrites: "Refactor entire module", "rebuild with better architecture", "start over with design pattern" (3x) → AI suggests wholesale changes when I need incremental improvements

**Layer 3 added:**

**Memory #1 - Code explanation calibration:**
When explaining concepts → Define technical terms on first use, assume beginner-intermediate → Don't use CS jargon → Self-taught means knowledge gaps

**Memory #2 - Progressive improvements:**
When suggesting improvements → Identify ONE thing to improve and how to fix it → Don't suggest rebuilding entire sections → Need to ship and learn incrementally

---

## Month 2: Expanded System (45 minutes additional)

### Layer 2 Expansions Added

**Operating Modes (added Week 4):**
- Mode 1: Career Strategy - multi-year perspective, market demand, honest timelines
- Mode 2: Active Coding - practical solutions, working examples, focus on shipping
- Mode 3: Concept Learning - educational depth, analogies, build from basics

**Decision Framework (added Week 5):**
- Priority 1: Demonstrable Skill Development
- Priority 2: Practical Completability
- Priority 3: Market Relevance
- Priority 4: Learning Efficiency

**Common Pitfalls (added Week 7):**
- Pitfall 1: Tutorial Hell - watching tutorials but not building
- Pitfall 2: Perfectionism Paralysis - endlessly planning, never shipping

### Layer 3 Additional Memory

**Memory #3 (Week 4) - Example-driven learning:**
When explaining new concepts → Start with concrete code example, then explain → Don't start with theory first → I learn by seeing it work

**Memory #4 (Week 6) - Project scope reality:**
When I propose project ideas → Pressure-test if completable in 2-4 weeks → Don't let me scope-creep into 3-month projects → Completed simple beats abandoned ambitious

**Memory #5 (Week 7) - Code review focus:**
When reviewing my code → Flag one critical issue and one learning opportunity → Don't list 15 things wrong → Too much feedback causes paralysis

---

## Evolution Summary

**Day 1:** Layer 1 (3 items) + Layer 2 (5 essentials) + Layer 3 (empty)

**Week 1:** Added 2 memory instructions from friction

**Month 2:** Layer 2 expanded (+3 sections), Layer 3 matured (5 total instructions)

**Total time:** 30 min setup → 15 min Week 1 → 45 min Month 2 = 90 min over 8 weeks

**Key insight:** Discovered tutorial hell and perfectionism through use, not upfront. Common Pitfalls section added Week 7 after recognizing my own behavior patterns.
